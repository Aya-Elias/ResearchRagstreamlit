# مساعد اكتشاف الأبحاث والإجابة التفاعلية (Streamlit)

تطبيق ويب محوّل من نوتبوك `paper_qa_pipeline` الأصلي — بيدوّر عن ورقة بحثية على
arXiv (أو تاخدي PDF بتاعك)، يلخصها، ويسيبك تسأليه أي سؤال عنها وهو بيرد بالاستشهاد بأرقام الصفحات.

## 1. التثبيت (مرة واحدة بس)

افتحي Terminal في مجلد الملفات وشغّلي:

```bash
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

> أول تشغيل هيكون بطيء شوية لأن `sentence-transformers` هيحمّل موديلات الـ
> embeddings والـ reranker (كذا مئات ميجا). بعد كده هتتخزن على الجهاز.

## 2. مفاتيح الـ API

هتحتاجي:
- **Groq API Key** (إجباري) — من [console.groq.com](https://console.groq.com)
- **Gemini API Key** (اختياري، بس لو هتفعّلي تحليل الصور) — من [aistudio.google.com](https://aistudio.google.com)

مفيش حاجة تتحط في الكود؛ هتدخليهم من القائمة الجانبية جوه التطبيق نفسه.

## 3. التشغيل

```bash
streamlit run streamlit_app.py
```

هيفتح التطبيق تلقائي على المتصفح على `http://localhost:8501`.

## 4. طريقة الاستخدام

1. حطي الـ Groq API Key في القائمة الجانبية.
2. اختاري "دوري في arXiv" واكتبي سؤالك أو الموضوع، أو "ارفعي PDF بتاعك" لو
   عندك ورقة جاهزة.
3. من نتائج البحث، اختاري الورقة اللي تناسبك.
4. استني المعالجة (تحميل → استخراج النص → تنظيف → تلخيص → بناء قاعدة المتجهات).
5. اسألي في صندوق المحادثة تحت — كل إجابة بتيجي بأرقام الصفحات اللي اتبنت عليها.
